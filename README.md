# خطوة Java — CS113

موقع عربي تفاعلي لمراجعة Java والتدرّب على فاينل اللاب. يبدأ من أساسيات Java 1، ثم الكائنات وUML والوراثة والواجهات والاستثناءات وrecursion، ويشمل الملفات وSwing وهياكل البيانات وGenerics.

## المحتوى

- 30 درسًا: شرح، مثال قابل للتعديل، تحدٍّ مستقل، تلميحات وحل مرجعي واختبار قصير.
- 74 مصطلحًا في دفتر التذكير، وأدوات لتتبّع المصفوفات وrecursion وفهم UML.
- أربعة نماذج لاب مع ملفات PDF الأصلية والمتطلبات والحلول ومحاكاة مؤقتة.
- 76 حالة فحص سلوكية تنادي دوال الحل الذي كتبه المتعلم. هذه فحوص تعليمية؛ لا تمنح درجة رسمية ولا تثبت وحدها صحة استخدام recursion أو مطابقة UML وكل تنسيقات المخرجات.
- محرر Java باستخدام CodeMirror، وتشغيل فعلي للمترجم والبرنامج داخل المتصفح عبر CheerpJ/OpenJDK.
- إدخال Scanner، وملفات افتراضية، وتجربة نوافذ Swing، وتنزيل ملفات Java والتقدم.

النسخة المرفقة من النموذج الأول لا تحتوي صفحة البرنامج الرئيسي؛ المثال الإضافي موسوم كتدريب. ترتيب صفحات النموذج الثالث داخل PDF هو 1، 4، 3، 2. يوضح الموقع أيضًا اختلاف توزيع الدرجات المطبوع في النموذج الرابع.

## التشغيل محليًا

الموقع ثابت ولا يحتاج خطوة build. من جذر المستودع، شغّل:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

ثم افتح [الموقع المحلي](http://127.0.0.1:8000). استخدم HTTP أو HTTPS؛ لا تفتح `index.html` مباشرة عبر `file://`.

لإيقاف الخادم، اضغط `Ctrl+C` في الطرفية.

## الملفات الأساسية

- `dist/index.html`: نقطة الدخول.
- `dist/app.js` و`dist/styles.css`: واجهة الموقع والتنقل والتقدم والاختبارات والأدوات.
- `dist/data/lessons.js`: الدروس والمصطلحات.
- `dist/data/exams.js`: متطلبات النماذج والحلول وملاحظات المصادر.
- `dist/data/checks.js`: أصناف Java الخاصة بالفحوص السلوكية.
- `dist/java-editor.js` و`dist/eclipse-editor.css`: إعداد محرر Java وألوانه.
- `dist/java-runner.js` و`dist/java-frame.*`: تحميل Java وتشغيل البرامج داخل المتصفح.
- `dist/assets/exams/`: أوراق الاختبارات الأصلية.
- `dist/assets/editor/`: ملفات CodeMirror وترخيصها ومصدر النسخة.
- `dist/assets/runtime/`: ASM وترخيصه؛ يستخدم لإيقاف الحلقات التي تستمر في استهلاك المعالج بلا انقطاع.

## الإنترنت والحفظ

الدروس وملفات PDF وملفات المحرر ضمن `dist/`. تشغيل Java يحمّل CheerpJ من شبكة CDN خارجية، ولذلك يحتاج اتصالًا بالإنترنت، خصوصًا عند التجهيز الأول. لا تتضمن هذه الحزمة بيئة Java كاملة للعمل دون إنترنت، ولا تضمن إعادة التشغيل بلا اتصال اعتمادًا على ذاكرة المتصفح المؤقتة. تُطلب الخطوط أيضًا من Google Fonts، مع خطوط بديلة عند تعذّر تحميلها.

ترجمة كود المتعلم وتنفيذه يجريان داخل المتصفح؛ لا يحتوي الموقع خدمة خادم لرفع الكود وتصحيحه. تحفظ المسودات والتقدم في تخزين المتصفح لهذا الموقع، وتوجد ملفات برامج Java في نظام ملفات افتراضي بالمتصفح. لا تُضاف هذه البيانات إلى المستودع ولا تُشارك مع زوار الرابط الآخرين. استخدم أداة النسخ الاحتياطي داخل الموقع قبل تغيير المتصفح أو مسح بياناته؛ يتعامل المتصفح مع رابط الاستضافة والرابط المحلي كموقعين مختلفين.

## النشر على Vercel

1. اختر **Add New → Project** واستورد هذا المستودع.
2. اترك **Root Directory** عند جذر المستودع. يحدد ملف `vercel.json` الإعدادات تلقائيًا: **Framework: Other**، مجلد النشر **dist**، وبدون أوامر build أو install.
3. اضغط **Deploy**. لا تحتاج متغيرات بيئة أو مفاتيح API.

راجع [توثيق إعدادات Vercel](https://vercel.com/docs/project-configuration/vercel-json). التنقل يعتمد على `#`، لذلك لا يحتاج rewrites. النسخة الخاصة على Sites وإعدادات مشاركتها مستقلة عن نشر Vercel.

## GitHub Pages أو استضافة ثابتة أخرى

انشر **محتويات `dist/` بوصفها جذر الموقع**. المسارات المستخدمة نسبية، وتناسب الاستضافة تحت مسار مشروع.

في GitHub Pages يمكن استخدام workflow من GitHub Actions يرفع المجلد `dist/` بوصفه Pages artifact ثم ينشره. ويمكن بدلًا من ذلك وضع محتويات `dist/` في جذر فرع نشر مخصص وتعيين ذلك الفرع مصدرًا لـPages. اختيار جذر هذا المستودع وحده لن يعرض الموقع، لأن `index.html` موجودة داخل `dist/`.

لا يتطلب الموقع خادم Java أو قاعدة بيانات. يبقى تحميل بيئة Java الخارجية مطلوبًا بعد النشر.

## المحرر وتجربة الدراسة

ألوان Java تحاكي سمة Eclipse الفاتحة: الكلمات المحجوزة أرجوانية، النصوص زرقاء، والتعليقات خضراء. التلوين نحوي؛ لا يتضمن تحليل رموز JDT الدلالي الكامل الموجود في Eclipse.

يمكن استئناف آخر درس وقسم، وإخفاء التنقل بوضع التركيز. سجل المحاولات يحفظ كود المحاولة الأصلية ويفتح نسخة مراجعة مستقلة. يظهر تنبيه دائم مع تنزيل نسخة احتياطية إذا فشل حفظ المتصفح.
